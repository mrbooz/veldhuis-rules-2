# ADR-0005: the export is final

Accepted · 2019-07-08 · BK

The Pay-Ready file is final once it has left the building. We do not amend a
sent file: a correction is a new line in the next fortnight's run, marked as
a correction, and the original stays exactly as sent. A file a customer's
payroll system has already read is a fact, and facts do not take edits.
