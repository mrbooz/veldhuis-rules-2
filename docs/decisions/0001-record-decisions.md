# ADR-0001: record decisions in this directory

Accepted · 2017-04-03 · WD

Decisions about the engine get written down here, one file per decision,
numbered in the order they are made. A record is never deleted and never
edited into a different decision: when a decision is reversed, a new record
says so and names the old one. The point is not process. The point is that in
five years somebody will have to change this code, and the contract that
explains it will be in a drawer in a building they have never visited.
